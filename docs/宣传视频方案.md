# 驭衡智控 · 60 秒宣传视频方案（草案，未生成）

形式：AI 氛围镜头 + 软件真实界面录屏，横屏 16:9、1080p、25 fps，字幕为主（可选配音）。
原则：凡是“软件能做什么”的画面一律用真实界面录制，AI 只负责氛围和转场——模型画软件界面会画错，
不能拿来当功能展示。

其余 7 个镜头是真实界面，镜头 12 由本地程序渲染，不产生模型费用。

## 真实界面怎么录

- 由脚本启动驭衡、开数字孪生运行，按分镜依次切页面并操作（阶跃、打开离线回放、生成日志），
  每 40 ms 截一帧窗口画面，合成 1920×1080 视频。不需要连接真实控制板，也不会碰硬件。
- 窗口固定 1920×1080、石墨橙主题、隐藏右侧诊断侧栏（镜头 9 除外），画面更干净。

## 合成

- 需要 ffmpeg（本机没有）。可以 `pip install imageio-ffmpeg`（自带 ffmpeg 可执行文件），不改系统环境。
- 字幕烧录，镜头之间 0.4 s 交叉淡化，片尾 1 s 淡出。
- 背景音乐需要你提供一段有授权的音乐；也可以不要音乐。
- 可选配音：用百炼 Qwen-Omni 按上表字幕生成中文旁白（同样按量计费，需要你另行确认）。
