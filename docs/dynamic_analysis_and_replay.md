# 时频、动态响应与算法验证

## 入口

- **离线傅里叶 → 时频与动态分析…**：沿用当前实机/CSV信号，勾选了蓝色选区时沿用其时间范围。无实机数据时也可打开窗口并使用“演示数据”。
- **数字孪生 → 算法验证 · ESO / RLS**：默认页。原整机仿真保留在第二个标签页。
- 分支启动：`HMI --tree codex`。合并到其他工作目录后，须在那个目录单独构建重放核心。

所有分析都是用户点击后执行的离线任务，不连接硬件、不改控制器参数，不接管实验回放。

## 时频分析

| 工具 | 设置及解释 |
| --- | --- |
| STFT | Hann窗，逐窗去均值，单边功率谱密度；频率间隔为采样率/窗长。缩短窗长提高时间定位能力，降低频率分辨能力。窗间默认约87.5%重叠，长记录会稀疏选窗，最多约1000个时间列。 |
| 小波系数能量图 | Morlet ω₀=6、L2归一化，80个线性频率点。显示\|W\|²，不是焦耳，也不是与MATLAB默认Morse/L1实现逐值一致的结果。按Morlet √2·scale 边界影响区留空，不把边缘伪影显示为可信结果。最多262,144个输入点。 |
| 阶次图 | 机械基准选rpm；电气基准选电角度°。按角度等间隔重采样后分窗FFT，显示阶次RMS²；横轴保留时间。4转窗对应0.25阶频率间隔。支持单向正/反转，拒绝停转、过零反转和角度分辨率不足的片段。 |

参考信号必须覆盖分析片段。机械阶次与电气阶次的基准不同，不能混选。
角域采样密度不低于原始数据在最低转速处的每转点数，避免角域降采样混叠；过大的转速跨度应分段分析。最高可用阶次按原采样率和最高转速限制，并保留10%余量。显示时把角域帧的非均匀时间位置插值到均匀图像列，导出保留原始帧位置和转速。

图上色标为**本图峰值归一化的相对功率dB**，因此不能仅凭两张图颜色判断哪次实验幅值更小。导出NPZ包含未归一化的功率、轴、时间和分析参数，可做定量比较；也可选择PNG直接保存图像。

输入上限2,000,000点。时间戳优先于CSV声明采样率；小幅时间抖动会线性插值到保持起止时间和点数的均匀网格。时间不递增、超过10%的采样间隔波动、NaN/Inf会明确拒绝，不会删掉坏点后伪造连续采样。需要先选取连续片段。

## 动态响应

先选实际响应信号及事件前后的连续片段，再填写**阶跃时刻和目标值**。目标值初始建议取末段中位数，分析未达到目标的过程时应手动填写真实给定。

- 基线：事件前末20%样本的中位数，至少5点。
- 上升时间：相对于基线到目标变化量的10%→90%首次跨越时间；下降阶跃也适用。
- 超调：相对于目标的最大超越量/阶跃幅度。
- 调节时间：最后一个超出可调误差带的点之后，直到记录末尾始终在带内，且至少满足设置的保持时间。否则显示未达到，不能断言未来不会再离带。
- 导数/加速度：Savitzky–Golay二阶多项式平滑导数。转速输入时单位rpm/s；其他信号显示相应单位/s，平滑窗可调。
- 振铃：越过目标的交替正负波瓣，正峰至少两个；突出度需达到阶跃幅度的2%，不把普通单调响应或小噪声当作振铃。报告峰间距中位数对应频率。
- 饱和：默认无分析。可指定真正的饱和标志信号，按前值保持对齐，非零视为饱和；也可明确选择当前信号绝对限幅推断。后者只是越限统计，不证明控制器实际发生饱和。导出占比与持续时间，图中用红点标出。

## ESO/RLS A/B验证

### 数据

支持当前监控页的同步F1批次、已有“RLS辨识数据.csv”，以及通用SI数据CSV：

```csv
time_s,rate_hz,id_a,iq_a,ud_v,uq_v
0.0000000,16000,0.01,1.20,0.3,2.0
0.0000625,16000,0.02,1.21,0.4,2.1
```

至少32点；固定采样率为正整数。可带`sample_seq`、`sample_index`用于连续性校验。旧格式无逐样本序号时会显示可验证范围。F1优先用PWM平均施加电压；旧数据回退到限幅后的控制指令电压，并明确标注来源。Id缺失时使用项目MCSDK Clarke/Park符号约定由Ia/Ib和电角度计算。

这里不通过不同绘图缓冲拼凑逐点输入，也不把16kHz数据直接当成10µs的Simulink仿真步。

### 比较方法

每组可选ESO或ESO＋ARX(3,两输入)RLS，分别配置ESO带宽、标称电感和遗忘因子。初始状态统一为零，保持已有一拍电压延迟的ESO更新约定。

预热阶段只更新ESO，RLS不自适应；之后训练至分割点，后段冻结RLS系数进行逐点预测。后段ESO仍用记录的测量值校正，ARX回归量也使用已知历史ESO电流。因此属于**单步预测验证，不是自由运行的多步预测或新控制器闭环验证**。

评价区间全部样本都参与C++误差累计，画面最多约5000点：

- ESO先验RMSE：当前测量尚未用于校正前的预测残差。
- ESO校正后RMSE：当前测量参与校正后的残差。高带宽可减小它，但不必然提高抗噪性。
- 冻结RLS误差：以ESO输出为目标的后段预测残差。不同ESO带宽改变辨识目标，不能只用这一项直接判定谁更准确。
- RLS系数图：显示本轴电压系数b₀；导出含全部7个系数随时间轨迹。任意ARX(3)系数不唯一对应电机物理R/L，本工具不把它标成物理参数辨识结果。

导出NPZ包含两组参数、完整评价区间的指标、绘图轨迹、数据来源和SI输入SHA256。绘图轨迹经过抽点，不能替代原始实验文件。

### 构建

运行需要NumPy、SciPy、PySide6和pyqtgraph；依赖已列入requirements.txt。编译需要对应Python的C++工具链（本机Python 3.11 / MSVC 2022）。

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_replay.ps1
```

产物位于本工作目录`native_replay_runtime/motor_replay_cpp.cp311-win_amd64.pyd`，不会安装到全局Python，也不会覆盖`native_core_runtime/motor_core_cpp...pyd`。重新构建前关闭正在使用此工作目录重放模块的进程。

复用`native_core/src/online_rls.cpp`，新增参数的默认值保留旧行为。黄金轨迹测试检查ESO逐样本结果及RLS训练段系数；精确Simulink参考配置只用于参考数据，不是F407电机参数。

现有整机Simulink DLL仍只接受转速/负载/Id给定。任意新Simulink子系统需导出测量输入、状态初始化和固定步接口后才能接入此验证工作流；此版本实现的是已接入的原生ESO/RLS。
