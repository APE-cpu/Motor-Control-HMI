# 实验信息与波形归档

## 使用

- 实验页默认打开“记录与数据”，顶部保留运行预检；设备参数、安全上限和可选方案放在“设备与方案”。
- 默认使用自由记录，无需逐步确认模板。选用旧模板时，原有必做步骤和状态检查仍生效。
- 实验名称、目的、操作者、设备名称、功率、母线和数据来源自动保存到记录根目录的 `_experiment_draft.json`。
- “设备实际版本”来自已就绪会话的身份上报。连接校验条件是用户档案白名单，接收版本信息不会改写白名单。
- “开始记录实验”仅开始数据记录，不启动电机。
- 监控页“保存所有波形”和采样诊断页 CSV 保存都会关联实验记录：有活动实验则归入该实验；否则创建独立的波形快照记录。
- 每次保存单独建子目录，不覆盖以前的 CSV/PNG。可从当前记录或历史记录打开数据目录。
- 数字孪生静态说明和通信遥测详情各自右上角有小 ×，独立关闭并记住状态；保留故障、运行状态及动态采样提示。

## 文件结构

```text
experiment_records/
  _experiment_draft.json
  2026/EXP-20260928-001/
    experiment.json
    device_snapshot.json
    controller_params.json
    protection_params.json
    telemetry.csv                 # 连续实验记录的慢遥测（有记录时）
    events.jsonl
    waveforms/<时间与唯一后缀>/
      export.json                 # 保存状态、文件索引、保存时的配置/身份快照
      波形.png
      原始数据.csv
      高速数据.csv                # 16 kHz F1 全程记录（旧版本名为 RLS辨识数据.csv）
    waveforms/<另一次保存>/
      export.json
      采样诊断.csv
    report/
```

旧“波形记录”目录中的数据保持原位，不自动搬迁。新快照记录的创建时间是保存时间，不代表整段缓冲数据的采集起点；CSV 保留自身时间轴和采样信息。只有完整实验记录才持续记录慢遥测和操作事件。

## 实现边界

- `experiments/exports.py` 保存导出票据绑定的实验编号。后台写盘期间即使实验结束或新建另一个实验，结果仍回写原实验。
- 每份 `export.json` 有 `saving / saved / failed` 状态。写盘失败保留已有文件，独立快照标记中止，不伪报成功。程序被强制终止可能留下 `saving`，需核对该目录。
- 大波形 CSV/PNG 继续后台写盘；保存完成后释放工作线程持有的数据快照。正常退出会等待用户完成正在进行的保存。
- 监控页移除旧 F4 突发抓取入口及绘图订阅，连续 F1 采样、解码、傅里叶和 CSV 数据保持原有通路。
- 不修改协议、下位机固件或 C++ 核，不连接实机。
