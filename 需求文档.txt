电机控制上位机软件需求规格说明书（v1.7 现状重写版）
====================================================

本文件由原始需求（PyQt5/PySide6、监控+控制+通信三页面）演化而来，
现按当前 v1.7.0 实际实现整体重写，作为功能与设计基线。代码与文档若
不一致以代码为准；本文档不是新增需求清单。

一、项目概述
----------------------------------------------------
本项目开发一套模块化的电机控制上位机软件，面向多类型电机
（PMSM、SRM、直线电机）的实时监控、控制策略下发、数据采集、
数字孪生仿真、参数辨识、矢量可视化、AI 异常检测与边缘 AI
推理、可追溯实验工作流。

软件采用模块化架构：每个功能（页面、控制算法、通信协议、
AI 模块）均独立成单独的 Python 文件，模块之间通过 Qt 信号
槽与统一接口交互，降低耦合度，便于单独维护、测试与升级。

软件是实验管理与运辅助工具，不替代下位机保护、硬件限流、
急停回路与高压安全连锁。500 V 平台的安全保护必须由独立硬件
回路实现。

二、技术栈
----------------------------------------------------
- 开发语言：Python 3.10+
- GUI 框架：PySide6（Qt 6）
- 绘图：pyqtgraph
- 串口：pyserial
- CAN：python-can / 周立功 ControlCAN.dll / 周立功 zlgcan.dll
- 深度学习：PyTorch
- 经典 ML：scikit-learn
- 推理：ONNX Runtime
- 数据：NumPy / pandas
- 知识库：BM25 本地检索 + pypdf + rapidocr_onnxruntime（可选）
- AI 客户端：OpenAI 兼容 HTTP 接口
- 打包：PyInstaller 单文件（runtime_paths.py 处理 _MEIPASS）
- 操作系统：Windows 10/11（Python 跨平台，未在其它系统验证）

四、主窗口与导航
----------------------------------------------------
- 左侧侧边导航栏，按 4 大组组织：
  * 运行控制：监控、电机控制、实验管理
  * 分析可视化：矢量可视化、功率流、参数辨识
  * AI 智能：AI 分析、边缘 AI、可选的模型训练
  * 系统：通信设置、电流采样诊断、操作记录、使用说明书
- 内容区用 ResponsiveStack（QStackedWidget 包装 QScrollArea），
  每页最小宽度 980 px，小屏自动滚动而非压缩
- 训练页在打包精简版（torch 不可用）或 --no-training 启动时
  自动隐藏

五、监控页面
----------------------------------------------------
- 实时显示：转速 / 电流 / 母线 / 转矩 / 角度 / 实际温度 /
  传感器质量
- 统计：转速、电流、转矩的最大值与最小值
- 趋势曲线：实际值与给定值同框对比，缓冲 1000 点，定时刷新
  100 ms
- 温度颜色提示：正常（绿）/ 高温（红），阈值 60 °C 与 85 °C
- 角度表低速直读机械角度，高速时带转向慢放示意
- 显示电频率 f_e = |n|·p/60
- 启动仿真只建立静止数据源，需显式启动命令才旋转；停止仿真
  会复位模型、遥测、角度表和矢量图
- 快速仿真演示入口：自动建立数字孪生环境、执行基础检查并
  启动电机，真机连接或故障锁定时禁用

六、电机控制页面
----------------------------------------------------
6.1 电机类型与参数
- 支持三种电机类型：PMSM、SRM、直线电机
- 电机参数：型号、极对数、最高转速限制（默认 4000 rpm）、
  电流限幅、额定工作点温度
- 实际温度来自遥测，用颜色提示

6.2 控制方式（按电机类型动态切换）
- PMSM / 直线电机：闭环 PI、开环、MPC、无位置传感器
- SRM：电流斩波控制（CCC）、角度位置控制（APC）、电压 PWM
  控制、MPC
- 每种控制方式有独立的参数面板，支持运行时动态调整与下发
- 切换控制方式时参数区域自动切换为对应面板

6.3 控制操作按钮
- 启动电机 / 停止电机 / 紧急停止（突出显示）/ 保存应用参数

6.4 保护边界
- 电流限幅限制数字孪生速度环输出的 q 轴电流给定，同时以
  max_current_a 随参数帧下发并冻结到实验保护快照
- 预检拒绝当前电流已越界的启动
- 该值不是安全认证的硬件限流；真机必须在下位机实现独立的
  电流给定限制、过流比较器、驱动保护与封波逻辑

七、位置传感器
----------------------------------------------------
- 7 种传感器，支持多选（主用 / 兜底 / 估算）：
  Hall / QEP / Resolver / SMO / EKF / MRAS / HFI
- 每种传感器在 config.SENSOR_REGISTRY 中维护元数据：
  sensor_id / bus / sample_rate_hz / can_id_default /
  allowed_modes / warn_modes / sensorless_method
- 每种传感器有独立参数 dataclass
- CMD_SET_SENSOR(0x21) 下发时按 sensor_id 切换下位机内部观测器

八、通信
----------------------------------------------------
8.1 通信方式
- 支持 RS-232 / RS-485 / CAN 总线 / TCP/IP，四种方式可热切换
- CAN 总线支持三种后端驱动：zlgcan（ControlCAN.dll VCI_*）、
  zlgcan-zcan（zlgcan.dll ZCAN_*）、python-can（slcan/pcan/kvaser）
- 完整可配置：端口、波特率、数据位、停止位、校验位、超时

8.2 v1 协议（默认兼容老固件）
- 帧结构：0xAA | CMD | LEN | PAYLOAD | 8 位累加和 | 0x55
- 串口遥测 payload 15 字节，struct 格式 <hHhHhbBBBx
- CAN 8 字节裸数据 <hHhH，无帧头/校验/帧尾
- 命令字：0x10 启动 / 0x11 停止 / 0x12 紧急停止 /
  0x13 故障复位 / 0x20 设置参数 / 0x21 设置传感器

8.3 v2 协议（实验工作流推荐）
- 帧结构：0xA5 0x5A | version | address | sequence | msg_type |
  command | length(2B) | payload | CRC16-CCITT-FALSE | 0x7E
- payload 上限 4096 字节
- 消息类型：COMMAND/ACK/NACK/HELLO/CAPABILITIES/TELEMETRY/
  HEARTBEAT
- 握手：HELLO/CAPABILITIES 协议版本协商 + 设备身份白名单
  （device_id / hardware_version / firmware_prefix），不匹配
  立即拒绝且不降级到 v1
- 心跳 0.5 s 周期、1 s 超时（联调初值）
- 安全例外：CMD_STOP / CMD_EMERGENCY_STOP 在会话未就绪时
  也允许发送
- 经典 CAN 不支持 v2（无分片协议）

8.4 三通道遥测
- 0xF0 常规遥测：10 Hz，15 B（串口）/ 8 B（CAN），慢变量
- 0xF1 高速遥测：200 Hz（UART）/ 1 kHz（TCP 批量），
  12/16/22 B 三档，电角度/Iq/Iqref/相电流/Vd/Vq/Vbus
- 0xF2 电流采样诊断：50 Hz，21/29/31 B 三档，
  ADC 原始值/PWM duty/扇区/标定窗口/VDDA
- 三通道独立时钟，每帧 tick_ms 为下位机 HAL_GetTick 毫秒
  时间戳；上位机额外存 monotonic_s 与墙上时间 ISO 字符串

8.5 异常处理
- 断线重连、超时提示、错误日志
- 运行状态机 FAULT_LOCKED 跨重连保持，必须显式复位

九、运行状态机
----------------------------------------------------
- 状态：DISCONNECTED / CONNECTED / PRECHECK / READY /
  RUNNING / STOPPING / FAULT_LOCKED
- 迁移约束：所有危险运行意图必须经状态机
- FAULT_LOCKED 跨重连保持，必须显式 reset_fault
- RUNNING/STOPPING 期间断线立即 FAULT_LOCKED
- 设备主动受控停机走 observe_device_stopped，无需上位机 STOP

十、数字孪生 L1
----------------------------------------------------
- communications/motor_sim.py 内置 PMSM dq 轴物理模型
- 积分方法：定步长欧拉法，0.5 ms 步长，每 0.1 s 对外吐一帧
- 高速轨迹 1 kHz（每 2 步采 1 次）
- 内嵌双闭环 PI：速度环 Kp=0.06/Ki=1.0，电流环 Kp=1.2/Ki=300
  （含交叉耦合前馈与抗饱和）
- L2 母线动力学：电源内阻、母线电容、带滞回的制动斩波器、
  过压跳闸
- 一阶热模型
- 默认参数为 48 V 小功率 PMSM 占位值，完整参数表见
  数字孪生与电机参数.md

十一、矢量可视化
----------------------------------------------------
- iα-iβ 电流圆与 ψα-ψβ 磁链圆双图实时绘制
- 带余辉点云与当前矢量线
- 仿真模式取 1 kHz dq 轨迹；真机模式由 10 Hz 遥测近似重构
- 几何解读：正圆=正常；圆度变差/偏心=不平衡/偏心/退磁征兆

十二、功率流
----------------------------------------------------
- 能量链路右侧显示实时计算公式与当前功率
- 主要计算：
  * 逆变器输入：P_inv = 1.5(vd·id + vq·iq)
  * 定子铜损：P_Cu = 1.5 Rs(id² + iq²)
  * 电磁功率：P_em = Te·ωm
  * 动能变化率：P_kin = P_em - P_fric/load
  * 电源输入与内阻损耗：P_src = Vsrc·Isrc，P_src-loss = Isrc²Rsrc
  * 制动电阻：导通时 P_brake = Vdc²/Rbrake
- 当前忽略逆变器开关损耗、铁耗与杂散损耗
- 真机未上报 dq 电压/电流或功率字段时，页面不猜测功率

十三、电机参数辨识
----------------------------------------------------
- 两点稳态 + 滑行实验，仅用转速与电流遥测辨识 B / Tc / J
- 稳态：Kt·iq = B·ω + Tc，两个转速点解出 B、Tc（Kt = 1.5·p·ψf）
- 滑行：J·dω/dt = -(B·ω + Tc)，最小二乘拟合 J
- ψf 需由铭牌或反电动势实验提供
- 仿真模式下可用虚拟电机真值验证辨识精度
- 辨识结果可一键写回数字孪生参数

十四、监督学习模型训练
----------------------------------------------------
- 6 种模型：MLP / 1D-CNN / LSTM / Transformer / 随机森林 / SVM
- 训练超参数：学习率、批大小、训练轮数、验证集比例、权重衰减、
  随机种子、优化器、损失函数、学习率调度
- 各模型独立的结构超参数面板
- 训练流程：数据采集 → 数据清洗 → 训练（实时 Loss 曲线）→
  ONNX 导出 → 边缘 AI 部署
- ONNX 导出仅支持 PyTorch 模型（不含 RF/SVM）

十五、深度强化学习训练
----------------------------------------------------
- 3 种算法：PPO（GAE 优势 + clip + DAgger）/ SAC（α 自动整定）/
  TD3（目标策略平滑）
- 环境：简化一阶电机模型 speed[k+1] = a·speed + b·u
- 状态 3 维 [speed, target, u_prev]，动作 1 维连续
- 奖励：-|speed-target|/1500 - 0.01·(u/u_max)²
- MPC 专家预热：训练前先用 MPC 生成专家数据集（41 点网格搜索，
  N=10 步前向），通过模仿学习预热策略网络
- DAgger 在线纠正：训练过程中周期性用 MPC 修正策略偏差
- 经验回放支持 CSV 导入导出

十六AI 集成
----------------------------------------------------
- 大模型分析：调用 OpenAI 兼容接口，对实时遥测进行自然语言诊断
- 图片理解：支持添加图片附件或一键抓取监控页波形截图，交给
  视觉大模型（如 qwen-vl 系列）判断电机运行状态与故障迹象
- 边缘 AI：在本地通过 ONNX Runtime 加载模型实时推理，输出
  异常分数 0~1，三档（<0.3 正常 / <0.6 警告 / ≥0.6 异常）；
  无模型时回退到基于规则的统计检测
- RAG 知识库：BM25 本地检索 + 中文字符二元组分词 + PDF OCR
  （rapidocr_onnxruntime 懒加载，结果按 mtime 缓存）

十七、实验工作流
----------------------------------------------------
- 实验模板：内置与用户自定义，含目的、数据源、设备参数、
  安全边界、引导步骤
- 不可变设备档案：每次保存产生新修订，旧修订不被覆盖；冻结
  电机、逆变器、控制板、传感器、固件身份与安全上限
- 标准流程：新建实验 → 配置核对 → 接线确认 → 运行预检 →
  实验动作 → 现象记录（快捷事件标记）→ 安全停机 →
  结构化结论 → 生成报告
- 报告输出：report.md、自包含 report.html、telemetry.svg
- 实验目录可直接复制进 Obsidian

十八、操作记录
----------------------------------------------------
- 所有关键操作（启动 / 停止 / 紧急停止 / 参数下发 / 训练 /
  导出 / 通信切换）均落盘到 logs/operation_log.txt
- 可在操作记录页面回看、搜索、级别筛选、逐行着色

十九、波形记录
----------------------------------------------------
- 高速波形 CSV 落盘到 波形记录/ 目录
- 文件名：波形_YYYYMMDD_HHMMSS.csv 与
  电流采样诊断_YYYYMMDD_HHMMSS.csv
- CSV 采用 utf-8-sig（带 BOM）编码
- 波形 CSV 长格式：channel, time_s, series, value
- 电流采样诊断 CSV 宽格式：与 0xF2 帧字段一致

二十、非功能性要求
----------------------------------------------------
- 界面美观：深色商务风格，配色协调，控件布局整齐，重要数据
  突出显示
- 响应性能：UI 操作流畅，数据更新不卡顿；后台 RX 线程持续
  读字节，主线程 QTimer 100 ms 批量刷新 UI
- 可扩展性：方便添加新控制算法、新通信方式、新电机类型、
  新模型
- 健壮性：通信异常不崩溃；参数输入合法性校验；CRC 错误静默
  跳过并计数；实验数据原子写（tmp + os.replace）+ fsync
- 跨线程安全：Qt 信号槽跨线程用 QueuedConnection，RX 线程
  不直接操作 UI
