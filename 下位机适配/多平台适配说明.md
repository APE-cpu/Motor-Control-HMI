# 上位机通信协议 — 多平台适配说明

## 文件结构

```
下位机适配/
├── protocol_portable.h      ← 串口协议头文件（所有平台共用）
├── protocol_portable.c      ← 串口协议实现（所有平台共用）
├── can_protocol_portable.h  ← CAN协议头文件（所有平台共用）
├── can_protocol_portable.c  ← CAN协议实现（所有平台共用）
├── v2_protocol_portable.h   ← v2串口/TCP协议头文件（CRC/握手/ACK）
├── v2_protocol_portable.c   ← v2无动态内存参考实现
├── V2_无功率级联调清单.md       ← v2控制板安全联调与验收步骤
└── platforms/
    ├── adapt_stm32_hal.c    ← STM32 串口适配
    ├── adapt_ti_c2000.c     ← TI C2000 串口适配
    ├── adapt_arduino.cpp    ← Arduino 串口适配
    ├── adapt_fpga.v         ← FPGA 串口实现
    ├── adapt_can_stm32.c    ← STM32 CAN适配
    ├── adapt_can_ti_c2000.c ← TI C2000 CAN适配
    ├── adapt_can_arduino.cpp← Arduino CAN适配（MCP2515）
    ├── adapt_can_fpga.v     ← FPGA CAN实现（MCP2515 SPI）
    ├── adapt_v2_stm32_hal.c ← STM32 HAL v2环形缓冲模板
    └── adapt_v2_ti_c2000.c  ← TI C2000 SCI v2环形缓冲模板
```

v1和v2是独立实现，迁移时二选一编入目标通信端口，不要在同一端口收到握手失败后自动切换协议。v2的UART/SCI中断只入环形缓冲，解析、命令门禁和应答必须放在主循环或通信任务。

## 一、串口协议（RS-232 / RS-485）

### 帧格式

```
[0xAA] [CMD] [LEN] [PAYLOAD × LEN字节] [CHKSUM] [0x55]
```

- CHKSUM = PAYLOAD 所有字节求和 & 0xFF
- 字节序：小端（Little-Endian）
- RS-232 与 RS-485 软件完全相同，仅物理层不同

### 命令字

| 命令字 | 方向 | 含义 |
|--------|------|------|
| 0x01 | 下位机 → 上位机 | 遥测数据（100ms 周期） |
| 0x10 | 上位机 → 下位机 | 启动电机 |
| 0x11 | 上位机 → 下位机 | 停止电机 |
| 0x12 | 上位机 → 下位机 | 紧急停止 |
| 0x20 | 上位机 → 下位机 | 设置参数 |

### 遥测 Payload（14字节）

| 偏移 | 类型 | 字段 | 说明 |
|------|------|------|------|
| 0 | int16 | speed_actual | 实际转速 rpm |
| 2 | uint16 | speed_target | 目标转速 rpm |
| 4 | int16 | current_actual | 实际电流 mA（A×100） |
| 6 | uint16 | angle_raw | 传感器原始值 |
| 8 | int16 | angle_actual | 实际角度 0.01°（deg×100） |
| 10 | int8 | temperature | 温度 °C+40 |
| 11 | uint8 | sensor_quality | 传感器质量 0-255 |
| 12 | uint8 | convergence | 观测器收敛度 0-255 |
| 13 | uint8 | flags | bit0=低速警告 |
| 14 | uint8 | padding | 填充 0 |

### 串口配置

| 参数 | 值 |
|------|----|
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |

### 各平台接入（串口）

**STM32 HAL（Keil / CubeIDE）**
1. 将 `protocol_portable.h/c` 和 `adapt_stm32_hal.c` 加入工程
2. 初始化时调用 `adapt_stm32_init()`
3. 串口接收回调里调用 `adapt_stm32_rx(byte)`
4. 每 100ms 填充 `ProtoTelemetry_t` 并调用 `protocol_send_telemetry()`

**TI C2000（CCS）**
1. 将 `protocol_portable.h/c` 和 `adapt_ti_c2000.c` 加入工程
2. 初始化时调用 `adapt_c2000_init()`
3. SCIA 接收中断里调用 `protocol_feed_byte()`
4. 每 100ms 调用 `protocol_send_telemetry()`

**Arduino**
1. 将 `protocol_portable.h/c` 和 `adapt_arduino.cpp` 放入 sketch 目录
2. 直接编译，`setup()` 和 `loop()` 已包含完整逻辑

**FPGA（Verilog）**
1. 将 `adapt_fpga.v` 加入工程，修改 `CLK_FREQ` 为实际时钟频率
2. 修改 `frame[]` 中的 payload 为实际传感器值
3. `tx` 引脚接 RS-485 驱动芯片（如 MAX485）DI 脚，DE/RE 拉高

## 二、CAN 总线协议

### 与串口协议的区别

CAN 模式使用**简化协议**，无帧头/校验/帧尾，直接发送 8 字节裸数据：

```
[speed_actual 2B][speed_target 2B][current_actual 2B][angle_raw 2B]
```

- CAN ID：默认 `0x100`（需与上位机通信设置页面一致）
- 波特率：500kbps（推荐）
- **CAN 仅用于遥测上报（下位机→上位机），控制命令仍走串口**

### CAN 遥测数据（8字节）

| 偏移 | 类型 | 字段 | 说明 |
|------|------|------|------|
| 0 | int16 | speed_actual | 实际转速 rpm |
| 2 | uint16 | speed_target | 目标转速 rpm |
| 4 | int16 | current_actual | 实际电流 mA（A×100） |
| 6 | uint16 | angle_raw | 传感器原始值 |

> 相比串口遥测，CAN 版本省略了角度、温度、质量等扩展字段，上位机会用上一帧数据补全。

### 各平台接入（CAN）

**STM32 HAL**
1. 将 `can_protocol_portable.h/c` 和 `adapt_can_stm32.c` 加入工程
2. 初始化时调用 `adapt_can_stm32_init()`
3. 每 100ms 填充 `CanTelemetry_t` 并调用 `can_proto_send_telemetry()`

**TI C2000（CCS）**
1. 将 `can_protocol_portable.h/c` 和 `adapt_can_ti_c2000.c` 加入工程
2. 初始化时调用 `adapt_can_c2000_init()`，并提前配置 CANA 邮箱 1 为发送模式
3. 每 100ms 调用 `can_proto_send_telemetry()`

**Arduino（MCP2515 模块）**
1. 安装 `MCP_CAN` 库
2. 将 `can_protocol_portable.h/c` 和 `adapt_can_arduino.cpp` 放入 sketch 目录
3. 修改 `adapt_can_arduino_init()` 中的 CS 引脚、波特率、晶振参数
4. 每 100ms 调用 `can_proto_send_telemetry()`

**FPGA（Verilog，外接 MCP2515）**
1. 将 `adapt_can_fpga.v` 加入工程，修改 `CLK_FREQ` 参数
2. SPI 引脚接 MCP2515：`spi_sck/mosi/miso/cs_n`
3. 修改 `TELEM_DATA` 常量为实际传感器值（64位，小端序）
4. 实际使用时将 `TELEM_DATA` 改为由寄存器动态填充

## 三、选择串口还是 CAN？

| 对比项 | 串口（RS-232/485） | CAN 总线 |
|--------|-------------------|----------|
| 遥测字段 | 完整（14字段） | 简化（4字段） |
| 控制命令 | 支持 | 不支持（需配合串口） |
| 布线距离 | RS-485 可达 1200m | 可达 1000m |
| 多节点 | RS-485 支持多从机 | 天然支持多节点 |
| 实时性 | 一般 | 较好 |

**推荐**：单节点验证用串口；多电机、强干扰环境用 CAN。

## 四、快速验证

上位机连接后，在**监控页面**应看到：
- 转速曲线实时更新
- 电流/转矩/温度显示正常
- 无"连接断开"提示

如果数据不显示：
- 串口：用调试助手抓包，确认字节以 `AA` 开头、`55` 结尾，校验和正确
- CAN：用 CAN 分析仪确认 ID=0x100 的报文每 100ms 出现一次，数据为 8 字节小端
