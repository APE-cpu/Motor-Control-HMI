# 电流看起来像噪声 / 不像正弦 {#troubleshoot-current-noise}
> 分组：排障 · 页面：monitor · 耗时：约 5 分钟 · 风险：只读排查
> 关键词：噪声, 电流跳, 不像正弦, 毛刺, 信噪比, 零偏, 偏置, 干扰, 654Hz, 共模, VDDA

## 步骤
1. 按 Ctrl+K 输入 `stats iq,ia,ib 1s`，看交流 RMS 相对电流幅值有多大
2. 输入 `fft ia 2s`，看尖峰是否为 fe 的整数倍
3. 打开“电流采样诊断”页，检查零偏和实测 VDDA
4. 切到“矢量可视化”，用“相电流 Clarke”模式看偏心和椭圆读数 {控件: vector.source}

## 预期
能判断问题属于“信号太小”、零偏/不对称，还是外部干扰。

## 失败时
| 现象 | 判断 | 处理 |
|---|---|---|
| 空载时波形乱、带载后变好 | 信噪比问题：0.01 Ω × 8 倍的采样链路满量程约 ±20.6 A，空载电流只占很小一部分 | 加负载提高电流；显示端可开 16 点平均（只影响显示） |
| 尖峰是 fe 整数倍 | 与电角度同步：零偏（1fe）、不对称（2fe）、死区（6fe） | 见 [[vector-roundness]] |
| 尖峰不是 fe 整数倍、静止时就存在 | 外部干扰，经 16 kHz 采样混叠而来 | 关 PWM 只采 ADC、换电源、改采样频率反推源频率 |
| Ia、Ib 中同幅同相 | 共模误差，来自两路采样共用的偏置、参考或地 | 查运放偏置与模拟地；Ic 是推算量，共模误差不会抵消 |

## 原理与公式
- 16 kHz 原始电流中约九成是白噪声；控制环里只能做 2~4 拍的轻滤波，16 点平均只适合显示，放进反馈会增加相位滞后。
- 实测 VDDA 正常范围约 3.25~3.35 V，随启停跳动说明模拟供电被污染。
- 混叠：电流每个 PWM 周期只采一次，真实频率 k·16000 ± f₀ 的干扰采样后都显示为 f₀。
