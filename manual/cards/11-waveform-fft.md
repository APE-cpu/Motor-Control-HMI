# 录波与频谱分析 {#waveform-fft}
> 分组：常用任务 · 页面：monitor · 耗时：约 2 分钟 · 风险：只读，不改变运行状态
> 关键词：录波, 波形, 保存, CSV, FFT, 频谱, 傅里叶, 谐波, 16kHz, 采样

## 步骤
1. 在“通信设置”把遥测档位设为“标准·16kHz”（需要以太网链路） {控件: communication.telemetry_level}
2. 运行中需要留存数据时，点“保存所有波形” {控件: monitor.save_waves}
3. 只想快速看频谱：按 Ctrl+K 输入 `fft iq 2s`，面板直接列出主要尖峰及其相对 fe 的倍数
4. 需要完整分析时打开“离线傅里叶”页，选择数据源与时间段

## 预期
CSV 保存在 `波形记录/` 目录，带 `sampling_rate_hz`、`source_filter`、`display_filter` 等列，可追溯采样率和滤波链路。
命令面板的 FFT 取自原始高速缓冲，不含显示滤波。

## 失败时
- 命令面板提示“没有可用的高速遥测数据”：检查是否已连接且遥测档位开启了 F1
- 2~16 kHz 连续 F1 报错：只有以太网链路支持
- 看到不是 fe 整数倍的尖峰：多半与转速无关，参考 [[troubleshoot-current-noise]]

## 原理与公式
- Park 变换把整条频谱平移 −fe：静止坐标系中频率 f 的分量，在 dq 中出现在 f − fe；fe = 转速 × 极对数 / 60。
- iq 是实数信号，只能看到 |f − fe|，看不到正负号；要分清正转/反转分量，需要对 id + j·iq 做双边 FFT。
- 常见对应：iq 中 1fe ← 静止系 0 Hz（零偏）；2fe ← 负序（三相不对称）；6fe ← 死区、反电动势 5/7 次谐波。
- 采样混叠：电流每个 PWM 周期只采一次（16 kHz），真实频率 k·16000 ± f₀ 的干扰采样后都显示为 f₀。
