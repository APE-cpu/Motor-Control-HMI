# 第一次闭环运行 {#first-run}
> 分组：快速上手 · 页面：monitor · 耗时：约 3 分钟 · 风险：电机会转动
> 关键词：启动, 运行, 闭环, 转速, 调速, 停止, 速度环, 第一次

先完成 [[first-connection]]。第一次运行请用保守的转速和电流限幅。

## 步骤
1. 在“电机控制”页确认最高转速，第一次建议用较低值 {控件: control.max_rpm}
2. 确认电流限幅（它不是硬件保护，只是下发到固件的软限幅） {控件: control.current_limit}
3. 点“发送当前参数到下位机”，等待 ACK {控件: control.apply}
4. 回到监控页面设置目标转速，第一次建议 300 rpm 左右 {控件: monitor.speed}
5. 确认电机周围无人、联轴器与负载已固定，然后点“启动” {控件: monitor.start, 危险}
6. 观察转速跟踪与电流；结束时点“停止”，等待状态回到 READY {控件: monitor.stop}

## 预期
转速收敛到目标附近，平均误差在几 rpm 以内；Iq 没有长时间顶在限幅上；状态栏和监控页没有故障提示。

## 失败时
- 启动被拒绝（NACK）：按 Ctrl+K 输入 `state` 查看连接、运行状态和故障码
- 状态不明、过流、过压或机械异常：立即用“紧急停止”或硬件急停 → [[troubleshoot-fault]]
- 不要在 ACK 超时或握手失败后反复带功率重启 → [[troubleshoot-connection]]

## 原理与公式
- 控制结构：速度 PI（500 Hz）输出 Iq 给定 → 电流 PI（16 kHz）→ PWM。
- 启动、停止等命令都需要设备 ACK；超时由运行状态机处理，界面显示的“已提交”不等于“已生效”。
- 正式的真机实验建议在“实验管理”页按“开始归档 → 预检 → 启动 → 停机 → 结束归档”执行；预检会拒绝电流已越界的真机启动。
- 电流限幅以 `max_current_a` 随参数帧下发并冻结进实验保护快照；真机必须同时具备下位机独立限流、过流比较器、驱动保护与封波逻辑。
